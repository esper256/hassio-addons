Dedicated [Factorio](https://factorio.com/) multiplayer server for Home Assistant OS. Downloads Wube’s free Linux headless package (not SteamCMD), automatic world backups, and an Ingress status UI for restore and troubleshooting.

Use the **Documentation** tab to configure the game server before you start it (including Space Age and public listing). After it is running, manage it with **Open Web UI**.
