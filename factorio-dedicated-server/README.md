# Factorio Dedicated Server

Dedicated **Factorio** multiplayer server for Home Assistant OS. Downloads Wube’s free Linux headless package (not SteamCMD), automatic world backups, and an Ingress status UI for restore and troubleshooting.

![OPEN WEB UI](images/ingress-ui.png)

**amd64 only.** After install, open the **Documentation** tab for configuration, ports, Space Age / public listing notes, and **OPEN WEB UI**.

Source and Docker: [github.com/esper256/hassio-addons](https://github.com/esper256/hassio-addons)
