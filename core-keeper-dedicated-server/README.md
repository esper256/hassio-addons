Dedicated [Core Keeper](https://store.steampowered.com/app/1621690/Core_Keeper/) multiplayer server for Home Assistant OS. SteamCMD updates, automatic world backups, and an Ingress status UI for restore and troubleshooting.

Use the **Documentation** tab to configure the game server before you start it (Direct Connect on UDP 7778 by default, plus a private Game ID; nothing is listed on a public browser). After it is running, manage it with **Open Web UI**.
