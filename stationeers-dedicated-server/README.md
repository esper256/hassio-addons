# Stationeers Dedicated Server

Dedicated **Stationeers** multiplayer server for Home Assistant OS. SteamCMD updates, automatic world backups, and an Ingress status UI for restore and troubleshooting.

![OPEN WEB UI](images/ingress-ui.png)

**amd64 only** (SteamCMD; image based on Debian Trixie for glibc). After install, open the **Documentation** tab for configuration, ports, and **OPEN WEB UI**.

Source and Docker: [github.com/esper256/hassio-addons](https://github.com/esper256/hassio-addons)
