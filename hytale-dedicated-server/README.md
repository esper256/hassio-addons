Dedicated [Hytale](https://hytale.com/) multiplayer server for Home Assistant OS. Downloads the official dedicated server with your Hytale account (device-code sign-in), automatic world backups, and an Ingress status UI for restore and troubleshooting.

Use the **Documentation** tab before the first start. After it is running, manage it with **Open Web UI** — first boot asks you to sign in twice (download, then server).
